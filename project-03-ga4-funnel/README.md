# Project 3: GA4 E-commerce Conversion Funnel

**Status:** Planned  
**Dataset:** Google Analytics 4 obfuscated sample ecommerce export in BigQuery  
**Tools:** BigQuery SQL, Google Analytics 4 event schema, Looker Studio

## Business problem

An online store wants to identify where shopping sessions drop out between product discovery and purchase.

## Data source

Google's public `bigquery-public-data.ga4_obfuscated_sample_ecommerce` dataset. It contains obfuscated sample event-export data for 2020-11-01 to 2021-01-31. Documentation: https://developers.google.com/analytics/bigquery/web-ecommerce-demo-dataset.

## Planned analysis

- Traffic and session acquisition.
- Product-view, add-to-cart, checkout and purchase funnel.
- Funnel conversion and drop-off by device and acquisition source.
- Purchase and ecommerce event analysis where fields support it.

## Limitations

The sample is obfuscated and historical. Placeholder values and limited internal consistency may affect interpretation. It is not the live Google Merchandise Store demo-account data.
