## Repository structure

- `docs/`: portfolio requirements, KPI definitions and business process documentation.
- `project-01-ecommerce/`: Olist data analysis, SQL, Power BI and findings.
- `project-02-salesforce-crm/`: synthetic CRM data, Salesforce setup and Tableau analysis.
- `project-03-ga4-funnel/`: GA4 BigQuery SQL and funnel analysis.
- `website/`: final GitHub Pages portfolio website (to be completed in Phase 8).

## Data and reproducibility policy

- Olist is real, anonymised Brazilian marketplace data. The dataset is licensed CC BY-NC-SA 4.0. Attribution and licence terms will be included in the project documentation. Raw source files will not be committed to this repository.
- The CRM dataset will be generated for this portfolio and is synthetic. It does not represent a real company or real customers.
- The GA4 BigQuery sample is Google's obfuscated public sample dataset. Its limitations will be disclosed.
- No private, confidential, medical, or personal customer data will be published.
- Findings will be based on actual query outputs. No results or business impact will be invented.

## Project status

The repository is currently a starter structure. Analysis, dashboards and findings will be added and marked complete only after validation.
